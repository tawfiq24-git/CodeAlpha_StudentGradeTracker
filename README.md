# Student Grade Tracker

## Overview

This is a Java console-based application developed as part of the CodeAlpha Java Programming Internship.

The program allows users to:

* Enter student names and marks
* Calculate average marks
* Find highest and lowest marks
* Display a summary report of all students

## Technologies Used

* Java
* Eclipse IDE

## Features

* Student data input
* Marks management
* Average calculation
* Highest and lowest score detection
* Console-based interface

## Output

The program generates a complete student report with marks and statistics.
